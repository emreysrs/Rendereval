## 2️⃣ Setup Your API Key

### Step 1: Get Your OpenAI API Key
1. Go to https://platform.openai.com/api-keys
2. Log in with your OpenAI account (or create one)
3. Click "Create new secret key"
4. Copy the key

### Step 2: Add to Environment File
Edit `.env.local` in your project root:

```env
OPENAI_API_KEY=sk-proj-your-actual-key-here
```

Replace `sk-proj-your-actual-key-here` with your actual OpenAI API key.

**Important**: Keep this file private! Add to `.gitignore` (already done ✅)

1. **Upload an Image**:
   - Drag and drop an image into the zone
   - Or click to browse and select a file

2. **Click "Analyze Lighting"**:

## 🐛 Troubleshooting

### Issue: "Failed to analyze image"
**Solution**: 
- Check that `OPENAI_API_KEY` is correctly set in `.env.local`
- Verify your OpenAI account has available credits
- Make sure it's a valid image file (JPEG, PNG, WebP, GIF)

### Issue: Port 3000 already in use
**Solution**:
```bash
npm run dev -- -p 3001
```
(Uses port 3001 instead)

### Issue: Module not found errors
**Solution**:
```bash
# Clear node_modules and reinstall
rm -rf node_modules
npm install
npm run dev
```

### Issue: API key not working
**Solution**:
- Restart the dev server after updating `.env.local`
- Make sure there are no extra spaces in the key
- Check key starts with `sk-proj-`
