                    TROUBLESHOOTING & FAQ

Q: "Failed to analyze image" error?
A: Check OPENAI_API_KEY in .env.local and restart dev server

Q: Port 3000 already in use?
A: Run: npm run dev -- -p 3001

Q: Module not found errors?
A: Run: npm install && npm run dev

Q: API key not working?
A: Make sure .env.local is in root directory, key is correct, and 
   you restarted the dev server

A: https://platform.openai.com/api-keys
